# made-up-case

One made-up spine for the 3D view's tests and gallery pages, fitted two
ways. Nothing in it comes from a patient.

| File | Holds |
|---|---|
| `fitted-spine.json` | the two-film fit, each film's geometry and size, and every vertebra's corners as marked and projected |
| `front-only-spine.json` | the same front corners alone, with no scale or pedicles, fitted with built-in typical values |
| `made-up-case.ts` | the two files above, typed |
| `front-film.png`, `side-film.png` | the films the marks are from, at a quarter of their size, 8 bits a pixel |
| `made-up-films.ts` | the two pictures, decoded for a gallery page |

## The case

The spine is the engine's made-up recipe `right-thoracic-40`, seed 3,
tier `t2`. The seventeen vertebrae from T1 to L5 are fitted by
`joint_fit::fit_spine` from the front and side films' true marks. The
front-only fit uses `joint_fit::fit_from_films`, built-in typical values,
no twist readings and a corner spread of 1.0 mm with no shared part.
Its front film has no stated scale, so its lengths are typical, not
measured; its pedicles are not visible, so twist comes from the typical
relation alone.

Both fits report their films' effective stored pixel spacings and the
upright pixel of the patient origin in `frontFilm` and `sideFilm`.
Those numbers, with the film's geometry and size, place the camera.
Each vertebra's `fitted` corners are the engine forward model's
`front_marks` and `side_marks` through that camera; `marked` corners
are the input marks. No camera is worked back from the bones.

The files are not regenerated by a repository command. The placing test
builds cameras from each fit's reported numbers and holds the bones to
both sets of projected corners and input marks. The parity test also
calls the release engine with the same made-up front corners, checking
the one-film fixture's poses and reported film placement.
